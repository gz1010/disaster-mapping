## backend-flood-bundle-api (11 review findings)

### Summary

- **R1 (major), fixed.** `manifest.data_sources` in a flood bundle now lists every source a build step used. Each entry is named by its credit line, the same text as that layer's `layer_status.source`. Newly credited: National Weather Service (plus the Census county shapes when warning zones are drawn as whole counties), NOAA NWPS with each gauge's own data attribution and each river forecast centre that issued a forecast, NASA OPERA with its route, the National Water Model (map and series) and the NWS category flood maps. A new test checks that every `ok` layer has a matching credit.
- **R2, fixed.** If the gauge step crashes, `gauges.json` is now marked unavailable (`GAUGES_UNAVAILABLE`) and the layer status says so. It no longer reads as "no gauge in this flood".
- **R3, fixed.** The backup NASA picture (GIBS) is now dated by satellite passes that actually cross the flood's area. The dates come from the Earthdata GIS catalogue, skipping passes a probe found with no view, or from NASA's CMR catalogue, which needs no login. If no such day exists, no picture is sent (`tiles` null, `SAT_NO_IMAGE`). A picture now carries a new reason, `SAT_PICTURE_REASON`.
  - On real data, the Platte River flood now gets Oct 30 instead of Oct 31. NASA's Oct 30 tile over it is 98.6% covered, all grey "no view"; the Oct 31 tile is empty there.
- **R4, fixed.** When there is simply nothing to map, the category flood map answer says so (`CATFIM_NOT_COVERED`, note `CATFIM_NOTE_ANY`). The "could not be loaded" text is kept for real outages.
- **R5, fixed.** No "?" cloud share reaches users any more. Pictures get `SAT_CAVEAT_NO_CLOUD_SHARE`, and radar images get `SAT_CAVEAT_RADAR`, which does not say clouds hide water.
- **R6, fixed.** The OPERA credit is now PLAN-5 §2's exact line, with the route before the Copernicus clause (`copy.opera_credit`). The GIBS picture uses the same line with "via NASA GIBS", because PLAN-5's shorter picture credit would drop the Copernicus clause the data licence asks for.
- **R7, fixed.** FEMA's "covers only part of this area" is now said only when partial coverage was measured. Otherwise the answer says it could not be checked (`NFHL_AVAILABILITY_UNKNOWN`)
